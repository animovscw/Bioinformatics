## Краткое описание фенотипа
Наследственный гемохроматоз 1 типа — это генетическое заболевание обмена железа, при котором усиливается всасывание железа в кишечнике и происходит его избыточное накопление в тканях организма. Наиболее часто поражаются печень, поджелудочная железа, сердце, суставы и кожа. Без лечения заболевание может приводить к циррозу печени, сахарному диабету, артропатии и другим осложнениям. Тип наследования — аутосомно-рецессивный.
